Android / Capacitor Guide

Is HTML file ko www/index.html ke roop mein rakh kar Capacitor ke saath Android project banaya ja sakta hai:

1. capacitor.config.json 
{
  "appId": "com.smartbachat.app",
  "appName": "Smart Bachat",
  "webDir": "www"
}
2. package.json scripts 
{
  "scripts": {
    "cap:add:android": "npx cap add android",
    "cap:sync": "npx cap sync android",
    "cap:open": "npx cap open android"
  }
}
3. Android Studio se .aab Build Karne Ke Steps
  1. www/index.html taiyar karein aur npm run cap:add:android chalayein.
  2. npm run cap:open se project Android Studio mein kholein aur Gradle sync poora hone dein.
  3. Top menu mein Build → Generate Signed Bundle / APK chunein aur Android App Bundle (.aab) select karein.
  4. Apni keystore file create/select karein (keystore ko surakshit rakhein) aur release build generate karein.
